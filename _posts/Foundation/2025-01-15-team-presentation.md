# Team Presentation: Teaching Programming Paradigms

## Overview
This presentation focuses on teaching the fundamental differences between procedural programming and object-oriented programming (OOP), emphasizing why OOP is important and how to build general JavaScript familiarity through structured learning experiences.

## Educational Framework Integration

### 9 Events of Instruction
Our presentation follows Gagné's Nine Events of Instruction to ensure effective learning:

1. **Gaining attention** - Opening with interactive demos and real-world examples
2. **Informing the learner of the objective** - Clear learning goals about programming paradigms
3. **Stimulating recall of prior knowledge** - Building on existing programming concepts
4. **Presenting information** - Structured content delivery through multiple modalities
5. **Providing guidance** - Step-by-step demonstrations and scaffolded learning
6. **Eliciting performance** - Hands-on coding activities and challenges
7. **Providing feedback** - Real-time assessment through checkpoints
8. **Assessing performance** - Formal evaluation of understanding
9. **Enhancing retention & transfer** - Connecting concepts to future applications

### Bloom's Taxonomy Application
The presentation incorporates multiple levels of Bloom's Taxonomy:

- **Remember**: Basic syntax and concept definitions
- **Understand**: Explaining differences between paradigms
- **Apply**: Using concepts in coding exercises
- **Analyze**: Breaking down complex systems into components
- **Evaluate**: Comparing procedural vs OOP approaches
- **Create**: Building original solutions using learned concepts
